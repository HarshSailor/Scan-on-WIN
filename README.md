# Scan on WIN

Бесплатная локальная программа сканирования для Windows 10/11 x64. Интерфейс на русском, светлая и тёмная темы. Исходный код — C# / .NET 8 / WPF, MVVM.

Scan on WIN — бесплатная программа для сканирования документов в Windows. Сохраняет страницы в PDF, PNG и JPG, распознаёт русский и английский текст. Есть поворот, обрезка страниц, предварительный просмотр и печать. Работает локально, без регистрации и подписки.
Создавал для себя, чтоб не платить за такие же программы подписку. Всё что бесплатное не видело мой МФУ Samsung SCX 4200 Series


## Установка

Запустите `dist/ScanOnWIN_Setup.exe`. Установка выполняется для текущего пользователя, создаёт ярлыки на рабочем столе и в меню «Пуск». Удаление доступно в настройках Windows. .NET, Tesseract и модели русского/английского уже включены; интернет при работе не требуется.

Портативный вариант: распакуйте **весь** `dist/ScanOnWIN-Portable.zip` в отдельную папку и запустите `ScanOnWIN.exe`. Не переносите один EXE отдельно от остальных файлов. «Портативный» означает отсутствие установки: настройки и восстановление документа по-прежнему находятся в `%LOCALAPPDATA%\ScanOnWIN`.

Сборка не подписана сертификатом издателя. Это исходный выпуск для проверки на вашем оборудовании; результаты проверок перечислены в `docs/TESTING.md`. Поддержка производителя сама по себе не гарантирует совместимость конкретной модели.

## Подключение сканера

1. Для USB установите WIA- или TWAIN-драйвер производителя, включите и подключите сканер.
2. Для сети включите eSCL/AirScan на совместимом устройстве и подключитесь к той же локальной сети. Автоматический поиск использует mDNS; сети с изоляцией клиентов или блокировкой multicast могут мешать обнаружению. В таком случае используйте сетевой WIA/TWAIN-драйвер производителя.
3. Нажмите «Обновить список устройств», выберите модель и интерфейс. Одно устройство может отображаться несколько раз: WIA, TWAIN 32-bit, legacy, TWAIN 64-bit, eSCL.
4. Если не удаётся получить параметры, включите «Открывать окно драйвера» для WIA/TWAIN. Для старых TWAIN-драйверов попробуйте legacy.

WIA и TWAIN работают с установленными драйверами, а не заменяют их. Драйверы HP, Samsung, Epson, Fujitsu/Ricoh, Canon, Brother, Xerox, Kyocera, Pantum и других производителей в установщик **не входят**.

## Сканирование и редактирование

Выберите источник (стекло/ADF/двусторонний ADF), DPI, цвет и формат листа. Списки учитывают возможности устройства. Если драйвер не сообщает часть параметров, программа предупреждает и предлагает стандартные значения; окончательную проверку выполняет драйвер. «Автоматический / вся область» передаёт выбор области драйверу и не обещает автоматическое определение границ бумаги.

«Сканировать» добавляет страницы в текущий документ. ADF обрабатывается до окончания бумаги. Для нескольких листов со стекла последовательно заменяйте оригинал и нажимайте «Сканировать». «Добавить страницы» делает то же самое. Предварительный просмотр со стекла выполняет настоящее сканирование на низком DPI и добавляет страницу в документ; при необходимости удалите эту страницу перед итоговым сохранением.

Справа выбирайте страницы и перетаскивайте их для изменения порядка. Стрелки ↑/↓ — альтернативный способ. На панели просмотра доступны 90°, 180°, 270°, масштаб и отмена правки. Для обрезки нажмите «Обрезать», выделите прямоугольник мышью и нажмите «Применить». Яркость/контраст применяются отдельной кнопкой. Все правки отображаются до сохранения; исходное изображение хранится для отмены. Автовыравнивание небольшого перекоса включается перед сканированием.

Во время сканирования и OCR окно остаётся доступным для отмены. TWAIN 32-bit обслуживается штатным x86-процессом SDK, TWAIN 64-bit — отдельным процессом Scan on WIN. Зависший 64-битный поиск ограничен 20 секундами, запрос возможностей — 30 секундами. При отмене сканирования 64-битный процесс завершается. WIA и x86 TWAIN получают сигнал отмены через SDK; некоторые драйверы завершают текущую передачу страницы до отмены. Перед закрытием окна дождитесь завершения операции.

## Сохранение и OCR

Выберите формат в списке «Формат сохранения» до нажатия «Сохранить». По умолчанию выбран PDF; последний выбор запоминается сразу. Расширение, введённое в имени, заменяется расширением выбранного формата.

- PDF: все страницы в одном файле. По умолчанию изображения без потерь. Для меньшего файла включите сжатие и выберите качество JPG (1–100).
- PNG: изображение без потерь для каждой страницы.
- JPG: отдельное изображение для каждой страницы, качество 1–100.
- TXT: многостраничный распознанный текст UTF-8; страницы разделены символом form feed.

Для нескольких изображений создаются `Scan_001.png`, `Scan_002.png` и т. д. Имя по умолчанию содержит дату и время. Выберите папку и нажмите «Сохранить» (`Ctrl+S`). Существующие файлы не перезаписываются: измените имя. Сначала формируется временный набор файлов, затем он переносится в папку назначения; при сбое исходные страницы остаются в рабочем документе.

OCR выполняется локальным Tesseract. Языки: русский, английский, русский+английский. В PDF остаётся оригинальный скан, а невидимый текст располагается по координатам слов. Его можно искать, выделять и копировать. TXT всегда запускает OCR, PDF — при включённом переключателе. PNG/JPG сохраняют только изображение. При ошибке OCR программа не выдаёт незавершённый результат за успешно сохранённый документ. Качество распознавания зависит от оригинала; для текста обычно подходит 300 DPI.

## Печать и поддержка разработчика

Кнопка «Печать» доступна, когда в документе есть страницы; предварительно сохранять файл не требуется. В окне просмотра выберите все страницы, текущую либо номера и диапазоны (например, `1, 3–5`). Копии, бумага, ориентация и цвет учитывают возможности драйвера. Кнопка «Печать…» открывает стандартный диалог Windows, где можно сменить принтер и его свойства.

Программа предлагает печатающую часть устройства, с которого получен текущий документ, только при однозначном совпадении. При нескольких совпадениях, разных источниках страниц или неизвестном источнике восстановленного документа выберите принтер вручную. Изображения вписываются в доступную область листа с сохранением пропорций.

Кнопка «Пожертвование» справа вверху открывает небольшое окно помощи разработчику. «Пожертвовать» открывает указанную ссылку в браузере Windows по умолчанию; платёжные данные программа не запрашивает.

## Сохранность и диагностика

Страницы, история правок и их порядок автоматически записываются в `%LOCALAPPDATA%\ScanOnWIN\document`. Следующий запуск восстанавливает текущий документ, в том числе несохранённый. Незавершённая передача драйвера не считается полученной страницей. Завершённые страницы из папки acquisition восстанавливаются при запуске. Один и тот же завершённый скан повторно не добавляется при восстановлении.

Рабочие изображения — это содержимое ваших документов, они остаются на локальном диске до начала нового документа. «Новый документ» очищает рабочую область после подтверждения. Удаление программы сохраняет папку данных. При необходимости удалите её вручную после сохранения всех документов.

Настройки: `settings.json`, журнал: `logs/diagnostics.log`, максимум два файла примерно по 1 МБ. Журнал записывает тип ошибки, код и имена методов, без OCR-текста, изображений, имён документов и сетевых адресов. Кнопка «О программе» показывает папку данных. При сбое чтения настроек используются значения по умолчанию.

Клавиши: `Ctrl+S` — сохранение, `Ctrl+N` — новый документ, `Ctrl+Z` — отмена правки, `F5` — поиск устройств, `Esc` — отмена операции.

## Архитектура

`ScanOnWin.App` — WPF, MVVM, команды и представление. `ScanOnWin.Core` содержит независимые службы:

| Модуль | Ответственность |
|---|---|
| ScannerDiscovery | Поиск и диагностика каждого интерфейса |
| WiaScanner / TwainScanner / Twain64Scanner / NetworkScanner | Реальное получение страниц через NAPS2 SDK |
| ScanProcessing | Поворот, обрезка, яркость/контраст |
| DocumentManager | Порядок страниц, история, атомарный манифест восстановления |
| PdfExporter / ImageExporter / DocumentExporter | Экспорт и безопасное завершение записи |
| OcrService | Локальный Tesseract, текст и текстовый слой PDF |
| SettingsService / LoggingService | Настройки и диагностика без содержимого документов |

Выбор .NET 8/WPF обеспечивает нативный Windows-интерфейс и совместимость с Windows 10/11. NAPS2 SDK используется как бесплатная LGPL-библиотека для сложного взаимодействия с драйверами, ADF, duplex, eSCL, обработки и координатного OCR/PDF. Приложение сохраняет собственные модули, страницы и интерфейс. Сборка self-contained; DLL оставлены отдельными, в том числе для замены LGPL-компонентов. Платных SDK, регистрации, телеметрии приложения, обновлений через интернет и облачного OCR нет.

Русские подписи сосредоточены в UI/модели представления; добавление английской локализации потребует вынесения строк в ресурсы. Английский OCR и англоязычный установщик уже доступны.

## Сборка из исходников

Нужны Windows 10/11 x64, **.NET SDK 8.0.426** (или совместимая версия 8.0.x с rollForward из `global.json`), PowerShell 7 и Inno Setup 6. Интернет нужен только для восстановления NuGet-пакетов; модели OCR включены в исходники. Если модели отсутствуют, скрипт скачает их из закреплённой ревизии и проверит SHA-256.

```powershell
pwsh -File .\scripts\Build.ps1
```

Если компилятор Inno Setup находится в другом месте:

```powershell
pwsh -File .\scripts\Build.ps1 -InnoCompiler 'C:\Tools\Inno Setup 6\ISCC.exe'
```

`-SkipInstaller` создаёт портативный архив без установщика, `-SkipUiTests` отключает оконные тесты в среде без рабочего стола, `-SkipTests` предназначен для повторной упаковки уже проверенной сборки. Скрипт останавливается при ошибках сборки, тестов или отсутствующих обязательных файлах.

Результаты: `dist/ScanOnWIN_Setup.exe`, `dist/ScanOnWIN-Portable.zip`, `dist/ScanOnWIN-Source.zip`, `dist/SHA256SUMS.txt`; развёрнутая автономная сборка — `artifacts/portable`. `ScanOnWIN.sln` включает приложение, Core и два тестовых проекта. GitHub Actions workflow `.github/workflows/windows-build.yml` выполняет сборку на Windows runner и сохраняет артефакты. Публикация в интернет из рабочей среды не выполняется.

Для разработки:

```powershell
dotnet restore ScanOnWIN.sln --locked-mode
dotnet build ScanOnWIN.sln -m:1
dotnet run --project src/ScanOnWin.App
dotnet run --project tests/ScanOnWin.Tests -- artifacts/test-results
dotnet run --project tests/ScanOnWin.UiTests -- artifacts/ui-tests
```

`--data-root <папка>` у приложения позволяет изолировать тестовый профиль. В рабочий список устройств MockScanner не включён: он существует только в тестовом проекте. Подробности: `docs/TESTING.md`.
